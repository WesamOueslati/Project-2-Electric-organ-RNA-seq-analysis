I propose that these data are strand-specific because 44.6278% and 56.3823% are on the reverse strand as opposed to the other strand. If our data were to be unstranded, we would expect both stranded=yes and stranded=reverse to have similar percentages of mapped reads.
Therefore, we should use the stranded=reverse for the counting if the library uses the reverse strand and the library is a first strand cDNA library.
