## Sanity Check (finding adapters in original file):
### Command
zcat FILENAME_R1 | grep AGATCGGAAGAGCACACGTCTGAACTCCAGTCA
zcat FILENAME_R2 | grep AGATCGGAAGAGCGTCGTGTAGGGAAAGAGTGT

Files are zipped so we have to zcat them then we search for the adapter sequences usign grep.
### Confirmation
- The adapter sequences are all locatted towards the end of the sequence.
- If they are at the end of the sequence then they are very likely to be adapter sequences.
- If they are near the end but not at the very end, then we check the sequences that follow them and compare them across the different reads. If they match then we can confirm that these are synthetic sequences from the library preparation 
- Finally, if there is a poly G sequence at the end, this tells us that this is the end of the sequence meaning that it was very likely an adapter. (I googled this and found out that illumina seq adds Gs when there is a lack of signal meaning that the there are still more cycles but we already reached the end of the strand)
